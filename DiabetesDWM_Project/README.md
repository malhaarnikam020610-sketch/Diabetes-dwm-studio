# 🩺 Diabetes Prediction XGBoost System

A complete, production-ready machine learning pipeline and interactive dashboard for diabetes risk prediction. 

This project encompasses synthetic data generation, an end-to-end XGBoost model training pipeline (including handling of class imbalances and hyperparameter tuning), along with a premium, responsive Streamlit dashboard.

## ✨ Features
- **Synthetic Data Generation:** Models realistic physiological correlations and distributions.
- **Robust Model Pipeline:** Uses `XGBoost` along with grid-search hyperparameter tuning, median imputation for missing values, and scale-pos-weight handling for class imbalances.
- **Extensive EDA & Evaluation:** Generates correlation heatmaps, feature distributions, confusion matrices, ROC curves, and feature importance graphs automatically.
- **Premium Dashboard (`Streamlit`):**
  - **Real-time Prediction:** Animated gauge and risk breakdown.
  - **Radar Profile:** Patient chart vs. population averages.
  - **Feature Contribution:** Understand exactly *why* the model made a prediction using median-baseline perturbation.
  - **Batch Prediction:** Upload CSV files to analyze multiple patients at once.
  - **Health Advice:** Personalized tips dynamically generated based on predictions and specific input metrics.
  - **Dark Glassmorphism UI:** Modern, aesthetic interface with micro-animation effects.

## 📂 Project Structure

```text
.
├── app.py                  # Streamlit dashboard application
├── data_generation.py      # Synthetic dataset generator script
├── model_training.py       # XGBoost training and evaluation pipeline
├── requirements.txt        # Python dependencies
├── diabetes_dataset.csv    # Generated dataset (created by data_generation.py)
├── diabetes_model.pkl      # Trained model pipeline (created by model_training.py)
└── plots/                  # EDA & evaluation charts (generated by model_training.py)
```

## 🚀 Quickstart

**1. Install Dependencies**
```bash
pip install -r requirements.txt
```

**2. Generate the Dataset**
Run the data generation script to create a fresh `diabetes_dataset.csv` with ~1200 patient records.
```bash
python data_generation.py
```

**3. Train the Model**
Run the training pipeline. This will process the dataset, perform GridSearch tuning, generate EDA/evaluation charts in the `plots/` folder, and save `diabetes_model.pkl`.
```bash
python model_training.py
```

**4. Run the Dashboard**
Launch the interactive Streamlit analyzer.
```bash
streamlit run app.py
```

## 📊 Dashboard Tabs
- **🔬 Prediction:** Adjust sliders to input patient vitals, view probability gauges, and review localized feature contributions.
- **📊 Dataset Explorer:** View dataset statistics, filterable data tables, distributions, and correlation maps.
- **📈 Model Insights:** View the static plots generated during training (Feature Importance, ROC, Confusion Matrix).
- **📤 Batch Prediction:** Drop a `.csv` file with batch records to process and classify several patients at once.
- **📤 Batch Prediction:** Upload a `.csv` with columns like `Gender, Glucose, BloodPressure, SkinThickness, Insulin, BMI, DiabetesPedigreeFunction, Age` to classify several patients at once.
- **📜 History:** Review a log of the predictions generated during your current session.
